# Putzz Pedia — Deploy

## Background animation
The site uses `assets/sasuke-animation.mp4` as a full-screen fixed background video. It is muted, autoplay, looping, responsive, and covered by a dark overlay so text remains readable.

## Firebase
Use the Firebase config already embedded in `index.html` and deploy the included `firestore.rules` to Firestore.

## Static hosting
Upload the entire `putzz-pedia-final` folder, including the `assets` directory. Do not upload only `index.html`, because the background video is required.
